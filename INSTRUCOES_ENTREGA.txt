GITHUB (etapa ainda pendente)
  1. No GitHub, crie um repositorio PUBLICO VAZIO, por exemplo radar-tech-blog.
  2. Abra o terminal na pasta radar-tecnologia do ZIP atualizado.
  3. Se o Git estiver instalado, rode os comandos a seguir, substituindo SEU_USUARIO:
     git remote add origin https://github.com/SEU_USUARIO/radar-tech-blog.git
     git push -u origin main
     git push origin comments categories
  4. Se 'origin' ja existir, use:
     git remote set-url origin https://github.com/SEU_USUARIO/radar-tech-blog.git
  5. Nao rode 'git init' nem recrie os branches: o historico ja esta no ZIP.

RENDER (etapa ainda pendente)
  1. Entre em render.com e conecte a sua conta GitHub.
  2. Escolha Blueprints > New Blueprint Instance e selecione o repositorio.
  3. Confirme a criacao dos servicos definidos em render.yaml (Web + PostgreSQL).
  4. Confira o funcionamento da URL publica apos o deploy.
  5. Copie os dois links (GitHub e Render) para os comentarios no Moodle.
